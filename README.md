# 📊 Dashboard de Demonstração

Este é um **Dashboard interativo** desenvolvido em **HTML, CSS e JavaScript** para fins de **portfólio**.  
Ele simula métricas de negócios (usuários, receita e clientes), com filtros dinâmicos e gráficos interativos.

---

## 🚀 Demonstração
👉 [Acesse aqui no Vercel](https://dashboard-demonstracao.vercel.app/)

---

## 🛠 Tecnologias Utilizadas
- **HTML5** → Estrutura do projeto  
- **CSS3** → Estilização responsiva e tema claro/escuro  
- **JavaScript (Vanilla)** → Lógica de filtros, KPIs e animações  
- **[Chart.js](https://www.chartjs.org/)** → Gráficos dinâmicos  

---

## 📌 Funcionalidades
✅ Filtros por **período** (7 dias, 30 dias, 90 dias, 6 meses, 1 ano)  
✅ Filtros por **canal** (Site / App / Todos)  
✅ **KPIs animados** (usuários ativos, receita, novos clientes)  
✅ **Gráficos interativos** (linha e barra)  
✅ **Tabela dinâmica** com busca e ordenação por colunas  
✅ **Tema claro/escuro** com alternância no botão 🌙  
✅ 100% **responsivo**, pronto para rodar em desktop e mobile
