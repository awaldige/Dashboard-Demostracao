# 📊 Dashboard de Demonstração

Dashboard interativo desenvolvido com **HTML5, CSS3 e JavaScript Vanilla**, criado para demonstrar visualização de dados, indicadores de negócios e construção de interfaces analíticas responsivas.

A aplicação utiliza métricas simuladas para apresentar KPIs, gráficos, filtros dinâmicos e uma tabela de dados interativa.

---

## 🌐 Demonstração Online

🔗 **Acesse o projeto:**
https://dashboard-demostracao.vercel.app/

---

## ✨ Funcionalidades

- 📊 KPIs animados
- 📅 Filtros por período:
- 7 dias
- 30 dias
- 90 dias
- 6 meses
- 1 ano
- 📈 Gráfico de linha para evolução das métricas
- 📊 Gráfico de barras comparativo
- 🔎 Busca na tabela de dados
- ↕️ Ordenação de dados
  
## 🌐 Filtro por canal:

- Site
- App
- Todos
- 🌓 Alternância entre tema claro e escuro
- 📱 Interface responsiva
- 📊 Métricas Simuladas

O dashboard apresenta dados demonstrativos relacionados a:

Usuários ativos
Receita gerada
Novos clientes
Evolução das métricas por período
Distribuição dos dados por canal

Todos os dados apresentados são simulados e têm finalidade exclusivamente demonstrativa.

## 🛠️ Tecnologias Utilizadas

- Tecnologia	Utilização
- HTML5	Estrutura da aplicação
- CSS3	Layout, responsividade e temas
- JavaScript Vanilla	Lógica e interatividade
- Chart.js	Criação dos gráficos

## 🚀 Como Executar Localmente
1. Clone o repositório
git clone https://github.com/awaldige/Dashboard-Demostracao.git
2. Acesse a pasta
cd Dashboard-Demostracao
3. Execute o projeto

Abra o arquivo index.html diretamente no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão atual do projeto.
