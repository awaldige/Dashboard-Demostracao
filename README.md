# 📊 Dashboard de Demonstração

Dashboard interativo desenvolvido em **HTML, CSS e JavaScript puro**, criado para fins de **portfólio** e demonstração de visualização de dados e métricas de negócios.

A aplicação simula indicadores como **usuários ativos, receita e novos clientes**, permitindo filtragem dinâmica e visualização por meio de gráficos interativos.

## ⚙️ Tecnologias Utilizadas

| Tecnologia | Função |
|------------|--------|
| HTML5 | Estrutura da aplicação |
| CSS3 | Layout responsivo e temas |
| JavaScript (Vanilla) | Lógica e interatividade |
| Chart.js | Gráficos interativos |

---

## 🚀 Funcionalidades

- ✅ Filtros por período (7, 30, 90 dias, 6 meses e 1 ano)
- ✅ Filtros por canal (Site, App ou Todos)
- ✅ KPIs animados
- ✅ Gráfico de linha para evolução de métricas
- ✅ Gráfico de barras comparativo
- ✅ Tabela dinâmica com busca e ordenação
- ✅ Alternância de tema claro/escuro
- ✅ Interface totalmente responsiva

---

## 📊 Métricas Simuladas

O dashboard apresenta:

- Usuários ativos
- Receita gerada
- Novos clientes
- Evolução de dados por período
- Distribuição por canal

Todos os dados são simulados para fins demonstrativos.
